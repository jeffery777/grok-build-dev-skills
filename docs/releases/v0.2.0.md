## 繁體中文

保留兩技能，新增明確編排指派的 inspect／plan／index-only refresh 薄入口。只重用固定 S/T 的三個 Python 模組與完整 LICENSE；套件為三十檔（含 manifest）。角色、唯一 writer、目標、profile 外部 digest、共用鎖與原 receipt 均須核對；技能、flags 或成功結果不創造授權。

[支援矩陣](../verification/gitnexus-operation-acceptance.md) 區分三層：原生 Grok 1.0.62 在隔離 fixture 完整讀技能／必要 Core 並執行一次唯讀 plan；既有 A02 controller 的一次實際寫入及其保留的外層 worker 例外；四項合成 Python 鎖驗證。原生停止案例只做假設情境推理。離線 41 項接入／package 測試與兩個技能 validator 是既有候選記錄，不是本次重跑或原生流程數量。

原生 refresh、實際拒絕／取消／恢復、跨代理並行、MCP/query 並存、正式 install/update/rollback 及其他平台未驗收；不重驗 vendor 功能或 sandbox。能力目錄及離線 packet 的 false readiness 不升級。後續交付仍需當前來源、獨立 review、必要安全檢查及 exact-head gates；本包保持未提交，不建立 tag／Release 或更動目前安裝。採用程序見 [安裝指引](../installation.md)。
